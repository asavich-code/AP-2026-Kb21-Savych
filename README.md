# Алгоритмізація і програмування — Кб-21

Здобувач освіти: **Савич Олексій**, група Кб-21 (№ 23 у переліку групи).

| Папка | Робота |
|---|---|
| `praktykum1_1` | Практикум 1.1 — блок-схема суми арифметичної прогресії (draw.io) |
| `pr1` | Практична робота №1 — блок-схеми, варіант 3 (draw.io) |

```bash
javac -encoding UTF-8 pr2/Lab2.java && java -cp pr2 Lab2
javac -encoding UTF-8 pr3/Lab3_Savych_Kb21.java && java -cp pr3 Lab3_Savych_Kb21
```
